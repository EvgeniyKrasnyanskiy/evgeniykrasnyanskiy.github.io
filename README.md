### 🛠 О проекте
Минималистичное веб-приложение, которое объединяет два моих интереса: программирование и отдых на природе.

*   **Визитка:** Краткая инфо и быстрый переход в Telegram.
*   **Чеклист:** Интерактивный список для сборов в поход:
    *   **Интерактивное редактирование названий** вещей прямо в списке (inline редактирование).
    *   **Сортировка по весу** внутри каждой категории (в обоих направлениях).
    *   **Подсчет общего количества позиций (вещей):** Отображает суммарное число вещей как внизу интерфейса чеклиста, так и в конце сгенерированного текстового файла отчета.
    *   **Умный Шеринг (Поделиться):** Генерация красивого текстового отчета по вещам с подсчетом позиций. На смартфонах использует нативный Web Share API (для мгновенной отправки в Telegram/WhatsApp), на ПК автоматически копирует отчет в буфер обмена и скачивает именной текстовый файл `checklist-[Имя_и_Маршрут].txt` с автоматической очисткой спецсимволов. Интерактивный запрос по умолчанию предлагает шаблон «Ваше имя и маршрут».
    *   **Текстовый Импорт (.txt):** Полноценный встроенный парсер отчетов. Вы можете загрузить ранее скачанный файл `.txt` обратно!
    *   **Интерактивный Предпросмотр:** При выборе файла импорта открывается красивое модальное окно предпросмотра со сводкой (категории, вещи, итоговый вес и оценка) до применения изменений.
    *   **Модальная Справка:** Вместо встроенного урезанного браузерного `alert()` реализовано премиальное прокручиваемое модальное окно со шкалой идеального веса, которое отлично отображается на любых экранах.
    *   **Оптимизация под мобильные:** Умный ввод веса с задержкой (debouncing) рендеринга и сохранением фокуса, что предотвращает скрытие клавиатуры на смартфонах при вводе цифр.
    *   **Сохранение состояния:** Автоматически синхронизирует состояние с `localStorage` браузера.

### 💻 Технологии
*   **HTML5 / CSS3 / ES6+:** Адаптивная верстка с поддержкой системной темной темы, анимации размытия (backdrop blur) для модальных окон.
*   **Vanilla JS:** Быстрая реактивная работа с DOM, Drag and Drop, дебаунсинг ввода, File/Blob/FileReader API.
*   **GitHub Pages:** Бесплатный хостинг прямо из этого репозитория.
