### 🛠 О проекте
Минималистичное веб-приложение, которое объединяет два моих интереса: программирование и отдых на природе.

*   **Визитка:** Краткая инфо и быстрый переход в Telegram.
*   **Чеклист:** Интерактивный список для сборов в поход:
    *   **Интерактивное редактирование названий** вещей прямо в списке (inline редактирование).
    *   **Сортировка по весу** внутри каждой категории (в обоих направлениях).
    *   **Шеринг (Поделиться):** Генерация уникальной ссылки на ваш собственный список с помощью Base64-сжатия в URL-хеше (использует нативный Web Share API на смартфонах).
    *   **Экспорт / Импорт:** Удобное модальное окно для копирования текстового JSON-кода списка или работы с файлами `.json`.
    *   **Оптимизация под мобильные:** Умный ввод веса с задержкой (debouncing) рендеринга и сохранением фокуса, что предотвращает скрытие клавиатуры на смартфонах при вводе цифр.
    *   **Сохранение состояния:** Автоматически синхронизирует состояние с `localStorage` браузера.

### 💻 Технологии
*   **HTML5 / CSS3 / ES6+:** Адаптивная верстка с поддержкой системной темной темы, анимации размытия (backdrop blur) для модальных окон.
*   **Vanilla JS:** Быстрая реактивная работа с DOM, Drag and Drop, дебаунсинг ввода, Base64 сериализация и файловое API.
*   **GitHub Pages:** Бесплатный хостинг прямо из этого репозитория.
