# Обновленный план реализации: Умный текстовый Импорт и Именные Файлы

Мы добавляем продвинутую и интуитивно понятную систему импорта обычных текстовых `.txt` файлов с интерактивным предпросмотром перед подтверждением и динамическим именованием файлов по имени пользователя.

---

## 📋 Новые изменения

### 1. Именные файлы экспорта
*   **Идея:** Вместо безликого `hiking-list.txt` мы будем автоматически считывать имя владельца из заголовка на главной странице (например, «Евгений») и называть файл в формате `checklist-Евгений.txt` (или `checklist-Имя.txt`).
*   **Реализация:**
    ```javascript
    const userName = document.querySelector('#page1 h1')?.textContent?.trim() || 'user';
    const fileName = `checklist-${userName}.txt`;
    ```

### 2. Умный парсер текстового файла (.txt)
*   **Решение:** Мы пишем надежный JS-парсер, который умеет читать простой текстовый отчет чеклиста и восстанавливать из него полную структуру категорий, вещей, их веса и статуса галочки (`[x]`/`[ ]`).
*   **Особенности:** Поддерживает любые изменения в файле, сделанные пользователем вручную (например, если он добавил новые строки в блокноте).

### 3. Интерактивное модальное окно предпросмотра (Preview Modal)
*   **Решение:**
    1.  Рядом с кнопкой «Поделиться» мы размещаем красивую кнопку «Импорт .txt».
    2.  При выборе текстового файла приложение не перезаписывает данные вслепую, а открывает **великолепное окно предпросмотра** с размытием фона (`backdrop-filter: blur`).
    3.  Окно показывает детальную сводку: имя выбранного файла, общее количество категорий/вещей, рассчитанный итоговый вес импортируемого списка (с цветовой оценкой) и прокручиваемый список всех распознанных вещей.
    4.  Пользователь может изучить список и нажать «Загрузить в чеклист» для применения или «Отмена» для возврата.
